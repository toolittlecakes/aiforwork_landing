# Roadmap для агентов — чек-лист, уровни обучения и позиционирование эфира

# Чек-лист: Структура и Уровни

- Три уровня прохождения:
  - Уровень 1: базовая настройка Codex, встроенные браузерные инструменты
  - Уровень 2: подключение к внешним сервисам, получение данных из открытых/закрытых источников
  - Уровень 3: автоматизация, скилы, проактивность
- Можно остановиться на любом уровне, но без второго уровня первый мало полезен
- Финал (генерация сайтов) оставить в конце как приятное дополнение
- Отдельный слайд с “no-go” зонами: например, deploy через GitHub — не трогать

# Содержание Чек-листа по Пунктам

- Уровень 1:
  - Прописать системные инструкции
  - Настроить горячие клавиши для диктовки
  - Встроенный браузер: аннотации, выделение HTML, правка через контекст агента
  - Встроенная память Codex: включить, понять механизм автозапоминания
  - Когда и зачем редактировать сообщение (vs. добавлять в очередь)
- Уровень 2:
  - Официальные плагины: подключить через меню
  - Подключение через MCP: попросить агента помочь, например, создать телеграм-бота
  - Неофициальные способы: скрипт для парсинга закрытых источников (пример: Telegram-канал)
  - Внешние инструменты: Slack и аналоги (не search/Google Sheets — они уже не нужны)
- Уровень 3:
  - Скилы: скачать, проанализировать, создать свой
  - Автоматизация повторяемых действий
  - Суб-агенты: делегирование задач, review с незамыленным взглядом
  - Ментор-агент: еженедельный разбор

# Позиционирование Эфира и Чек-листа

- Чек-лист сам по себе ценность: выстраданный порядок, без лишнего, одна страница
  - За каждым пунктом стоит опыт команды и участников прошлых потоков
- Эфир добавляет: детали, подводные камни, ответы на вопросы в прямом эфире
- Название: не “полезный чек-лист” (замылено), а road map с конкретными задачами
  - Акцент: для людей с экспертизой вне разработки, которым нужно закрывать операционные задачи
  - Не про vibe coding и создание приложений, а про то, чтобы агент делал вашу работу
- Воронка:
  - Чек-лист → эфир (детали + Q&A) → марафон (персонализированный трек, группа, поддержка)
- Аргумент против “человеческой коммуникации” как базовой ценности: непродающий угол, слишком абстрактно
