10Три уровня

Что меняется после каждого ряда

11Самодиагностика

Что из этого вы уже делали сами?

Быстро отметьте знакомые действия — без экзамена и долгих раздумий.

Настроил Codex: инструкции, разрешения, рабочая папка
Получил готовый документ, таблицу, слайд или сайт
Использовал память, субагента или встроенный браузер
Подключил рабочий сервис через плагин, API или MCP
Добыл данные там, где готового подключения нет
Сохранил процесс как skill или запустил по расписанию

Первое незнакомое действие подсказывает, куда двигаться дальше.

13Красные зоны

Что пока сознательно не трогаем

  • Публикацию приложений через GitHub и серверы
  • Массовые действия в рабочих аккаунтах
  • Платежи
  • Публикации и удаления без подтверждения
  • Чувствительные рабочие данные без политики и обезличивания

«Технически возможно» ≠ «хорошая учебная задача».

13До roadmap

Шаг 0: добиться, чтобы Codex просто запустился

Что потребуется
  • Рабочий VPN и аккаунт
  • Подписка с доступом к Codex
  • На Windows — отдельная настройка по инструкции
Когда готово

Codex открывается, видит вашу рабочую папку и может выполнить простую команду.

На эфире не будем устанавливать всё вместе. Дадим инструкции, а на марафоне поможем, если настройка застопорит.

15Узел 01 · Настройка

Задача 1: настроить Codex под себя

Что настроить
  • Системные инструкции
  • Разрешения и безопасные границы
  • Доступ к рабочей папке
  • Нужные программы
  • Диктовку и горячую клавишу
Что сделать руками
  • Описать себя и свою работу в системных инструкциях

Задача выполнена, если

Агент учитывает ваш контекст, работает в нужной папке и спрашивает подтверждение перед рискованным действием.

21Узел 02 · Практика

Задача 2: получить готовый результат для работы

Выберите одну задачу
  • Собрать таблицу из нескольких файлов
  • Оформить документ или презентацию
  • Провести исследование и собрать отчёт
  • Сделать простую страницу или сайт
Условия
  • Реальные материалы из вашей работы
  • Заранее понятный формат результата
  • Заранее понятный способ проверки
  • Одна задача, а не четыре сразу
Задача выполнена, если

Файл можно открыть, проверить и сразу использовать или отправить — без ручной пересборки из ответа в чате.

24Узел 03 · Встроенные усилители

Задача 3: попробовать три встроенные возможности

ПамятьСохранить контекстДайте агенту факт о вашей работе и проверьте его в новой сессии
→
СубагентПолучить второй взглядПопросите отдельно проверить результат или исследовать часть задачи
→
БраузерПроверить глазамиОткройте сделанный сайт и попросите исправить то, что видно на экране

Это уже есть внутри Codex. Никаких плагинов, MCP и автоматизаций пока не нужно.

26Узел 03 · Управление работой

Три способа поправить агента, не начиная заново

EditПереписать задачуЕсли вы с самого начала попросили не то
ReplyНаправить по ходуЕсли общий путь верный, но нужна поправка
QueueЗапланировать дальшеЕсли уже знаете, что агенту делать после текущего этапа
Когда остановиться

Если направление неверно целиком — исправьте исходную постановку, а не стройте башню из уточнений.

Задача выполнена, если

Вы довели многошаговую работу до результата и понимаете, какой из трёх способов использовать в следующий раз.

31Шаг 04 · Plugins

Сначала попробуйте PLUGINS — готовые подключения

Plugin даёт Codex доступ к сервису без самостоятельной настройки API и MCP.

Google DriveНайти и собратьНайти документы по теме и сделать по ним сводку
GranolaРазобрать встречиСобрать решения и задачи из нескольких созвонов
ChromeРаботать в браузереИспользовать уже открытые вкладки и вашу сессию
Задача выполнена, если

Вы подключили один plugin, дали задачу на своих данных и сверили результат с источником.

34Шаг 05 · API и MCP

Если плагина нет: API или MCP

API

Служебный вход в сервис

Через него Codex получает данные или выполняет действие без кликов в интерфейсе.

MCP

Готовый переходник для агента

Он описывает Codex, какие данные и действия доступны в сервисе.

hh.ruПолучить вакансии и собрать таблицу
Telegram-ботПринять запрос и прислать результат
Яндекс МетрикаЗабрать цифры и обновить отчёт

Вам не нужно писать интеграцию вручную: вы формулируете задачу, Codex помогает пройти настройку.

36Шаг 05 · Задача

Задача 5: подключить один нужный сервис

Порядок
  • Назвать сервис и конкретные данные или действие
  • Попросить Codex найти официальный способ подключения
  • Создать ключ или подключить MCP по его инструкции
  • Сначала прочитать данные; действия добавить после проверки
Красные флаги
  • Класть ключи в чат или в общий документ
  • Давать ключ с максимальными правами
  • Подключать ради подключения — без задачи
Задача выполнена, если

Codex получил реальные данные из сервиса, ключ не попал в чат или общий файл, а результат совпал с источником.

38Шаг 06 · Неофициальные способы

Внешний браузер — последний способ подключения

Когда оправдано
  • У сервиса нет ни интеграции, ни API
  • Данные или действия доступны только на сайте
  • Начинаем с чтения страницы, не с действий
Цена
  • Хрупко: интерфейс поменялся — сломалось
  • Медленнее и дороже прямого доступа
  • Требует наблюдения, а не «запустил и ушёл»
01ОфициальноеЕсть готовая интеграция
→
02API / MCPЕсть служебный вход
→
03БраузерДругих путей нет

43Шаг 07 · Skills

Skill — удачный процесс, записанный как инструкция

Инструкция хранит ваши правила, формат и критерии качества. Это текст: его можно прочитать, проверить и поправить.

Готовый
  • Скачать для типовой задачи
  • Прочитать инструкцию перед запуском
Свой
  • Собрать из удачного прогона
  • Проверить на новых данных
Обновить
  • Исправлять инструкцию, а не промпт каждый раз
  • Хранить понятную рабочую версию

Промпт — просьба на один раз. Skill — процесс, который переживает сессию.

45Шаг 07 · Задача

Как сделать свой skill

Порядок
  • Взять задачу, которую вы уже успешно сделали с Codex
  • Попросить Codex превратить удачный процесс в skill
  • Прочитать и поправить получившуюся инструкцию
  • Запустить skill на новых данных
Красные флаги
  • Писать skill до первого удачного прогона
  • Пытаться уместить всю работу в один skill
  • Не проверять повторный запуск
Задача выполнена, если

Повторный запуск на новых данных дал такой же пригодный результат без повторного объяснения процесса.

47Шаг 08 · Автоматизации

Автоматизация — skill, который запускается сам

По таймеруНапример, каждый понедельник утром
В облакеЗапуск не зависит от открытого ноутбука
Как «ментор»Сам приходит с еженедельным разбором и вопросами
  • Взять skill, который уже стабильно работает вручную
  • Назначить расписание и место, куда должен прийти результат
  • Дождаться первого самостоятельного запуска и проверить итог
Задача выполнена, если

Задача запустилась без вашей команды — и результат пришёл туда, куда вы ждали.

49Шаг 09 · Вайбкодинг

Вайбкодинг: вы описываете инструмент, агент пишет код

01ОписатьЧто должен видеть и делать пользователь
→
02Собрать и открытьCodex делает страницу и показывает её в браузере
→
03ОпубликоватьСтраница открывается по ссылке и передаёт данные
  • Выбрать маленькую страницу или форму, которой не хватает в работе
  • Описать словами, что она должна делать — агент соберёт
  • Опубликовать и открыть по ссылке с другого устройства
  • Проверить, что данные действительно доходят до таблицы
Задача выполнена, если

Инструмент работает по ссылке у другого человека — данные пришли туда, куда вы ждали.

53Самостоятельный путь

С этим roadmap можно идти самостоятельно

Что останется после эфира
  • Порядок из девяти шагов
  • Конкретная задача на каждый шаг
  • Критерий, по которому идти дальше
  • Чек-лист, который можно проходить в своём темпе
Что обычно требует больше всего сил
  • Первая настройка и доступ
  • Выбор задачи подходящего размера
  • Разбор непонятной ошибки
