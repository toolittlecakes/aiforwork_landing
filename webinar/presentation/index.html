11Правила маршрута

Как проходить карту

  • Шаги идут только по порядку — без перепрыгивания к автоматизациям
  • Внутри каждого шага — одна задача из вашей работы, а не все примеры сразу
  • Примеры сервисов — иллюстрации класса возможностей, не обязательный чек-лист
  • Дальше — только после понятного проверяемого результата

Не осваивайте всё одновременно. Один понятный уровень за раз.

31Узел 04 · Официальные подключения

Что это
  • Подключение без ключей и настройки

  • Начать с задачи на чтение
  • Сверить результат с источником
Не делать
  • Подключать всё сразу
  • Начинать с действий
  • Верить сводке без проверки

34Узел 05 · API и MCP

API и MCP: что это и что открывает

API

Служебный вход в сервис

Сервис отдаёт данные и принимает команды напрямую, без интерфейса.

MCP

Переходник для агента

Единый стандарт: агент сам понимает, что сервис умеет.

hh.ruСвести вакансии или отклики
TelegramПринимать задачи и присылать результат
МетрикаЗабирать статистику в отчёт

Это классы возможностей, а не обещание готовых интеграций.

36Узел 05 · Практика

Одно подключение через API или MCP

Сделать
  • Выбрать сервис, где официальной интеграции не хватает
  • Получить ключ или подключить MCP — агент проведёт по шагам
  • Начать с чтения данных, действия — после проверки
  • Довести до артефакта, который входит в работу
Красные флаги
  • Класть ключи в чат или в общий документ
  • Давать ключ с максимальными правами
  • Подключать ради подключения — без задачи
Gate

Агент получил данные или выполнил действие там, где готовой кнопки не было. Ключи защищены, права минимальны, результат сверен.

38Узел 06 · Браузер

Браузер — последний способ подключения

Когда оправдано
  • У сервиса нет ни интеграции, ни API
  • Задача видна только в веб-интерфейсе
  • Начинаем с чтения страницы, не с действий
Цена
  • Хрупко: интерфейс поменялся — сломалось
  • Медленнее и дороже прямого доступа
  • Требует наблюдения, а не «запустил и ушёл»
01ОфициальноеЕсть готовая интеграция
→
02API / MCPЕсть служебный вход
→
03БраузерДругих путей нет

Одна задача выполнена под присмотром, результат сверен с экраном, и вы понимаете, почему не подошёл более простой способ.

43Узел 07 · Skills

Skill — процесс, записанный один раз

Инструкция хранит ваши правила, формат и критерии качества. Это текст: его можно прочитать, проверить и поправить.

Готовый
  • Быстрый старт для типовых процессов
  • Сначала прочитать, что внутри, потом применять
Свой
  • Для процессов, которые есть только у вас
  • Начинается с одного удачного прогона задачи

Промпт — просьба на один раз. Skill — процесс, который переживает сессию.

45Узел 07 · Практика

Один процесс — один skill

Сделать

  • Прогнать его с агентом до принятого результата
  • Сохранить удачный прогон как skill
  • Запустить skill повторно на новых данных
Красные флаги
  • Писать skill до первого удачного прогона
  • Пытаться уместить всю работу в один skill
  • Не проверять повторный запуск

58Кому не подходит

Честные ограничения

  • Не подойдёт, если нет времени на практику — карта проходится руками, не просмотром
