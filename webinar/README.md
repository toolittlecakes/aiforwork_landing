## Структура

```text
webinar/
├── presentation/                  # актуальная HTML/PDF-презентация и её ассеты
├── references/
│   ├── dasha/                     # видео, транскрипт, слайды и reverse engineering референса
│   └── meeting-2026-08-10/        # полная запись нашего обсуждения и выводы для вебинара
├── inputs/                        # материалы, которые задавали контекст, но не являются сценарием
├── drafts/                        # промежуточные варианты структуры вебинара
└── archive/                       # старые версии презентации, Fable-прототип и устаревшие QA-рендеры
```

## Что является source of truth

1. Слайды редактируются в [`presentation/index.html`](./presentation/index.html).
2. PDF и изображения — производные артефакты; после изменений их нужно экспортировать заново.
3. Последовательность из девяти шагов задаёт исходная картинка [`inputs/roadmap-original.png`](./inputs/roadmap-original.png): три ряда по три узла, маршрут идёт змейкой без веток.
4. Материалы Даши — структурный референс, а не источник текста для копирования.
5. Выгрузка бота и встреча 10 августа — контекст и формулировки команды, но сам вебинар проектируется с нуля.

## Тяжёлые локальные файлы

Папка содержит около 450 MB локальных исследовательских материалов. Исходное видео Даши, 154 извлечённых кадра, scene detection, contact sheets, текущие PNG-рендеры и весь `archive/` находятся в этой структуре, но исключены из Git через `.gitignore`. Они остаются доступны на этой машине; в новом clone их не будет.

Подробная карта референса находится в [`references/dasha/README.md`](./references/dasha/README.md), а команды работы с презентацией — в [`presentation/README.md`](./presentation/README.md).
